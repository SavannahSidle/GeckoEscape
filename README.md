# Gecko Escape 1

A tiny browser escape game from Alien Arboreal focused on five reptiles and amphibians. Gecko Escape 2 is a separate game.

## Play

- Move: WASD or arrow keys
- Jump: Space or Up
- Primary ability: E
- Secondary ability: R, when available
- Touch controls appear automatically on mobile devices

Collect every required prey item, avoid hazards, and reach the exit. The game runs entirely in the browser with no dependencies.

## Story mode

1. The Enclosure
2. The Aquarium
3. The Kitchen

Playable characters: chameleon, crested gecko, fire-belly newt, azureus dart frog, and black Colombian boa.
