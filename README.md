# Gecko Escape

A browser escape game from Alien Arboreal. The original game follows five reptiles and amphibians through six story levels.

## Play

- Move: WASD or arrow keys
- Jump: Space or Up
- Primary ability: E
- Secondary ability: R, when available
- Touch: use the on-screen movement stick and action buttons. The movement stick has an enlarged invisible touch area.

Collect the required prey, avoid hazards, and reach the exit. If a grabbing hand catches the animal, it holds the animal briefly before dropping it and costing a life. Touch and keyboard inputs clear when the page loses focus.

## Story levels

1. The Enclosure
2. The Aquarium
3. The Kitchen
4. The Living Room
5. The Highway
6. Boat Escape

Playable characters: chameleon, crested gecko, fire-belly newt, Azureus dart frog, and black Colombian boa.
