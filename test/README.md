# Gecko Escape 1 · Test build

This isolated build is served from `/test/`; the main game files are separate.

## Play

- Move: WASD or arrow keys
- Jump: Space or Up
- Primary ability: E
- Secondary ability: R when available
- Touch: use the movement stick and on-screen action buttons

## Story levels

1. The Enclosure
2. The Aquarium
3. The Kitchen
4. The Living Room
5. The Highway

Choose one of the five reptiles or amphibians, collect its prey, avoid the hazards, and reach the exit. The browser build has no external runtime dependencies.
